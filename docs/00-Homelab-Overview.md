# Homelab Overview

## Purpose

This homelab is a practical Linux and infrastructure learning environment built around Fedora, Docker, network storage, self-hosted services, Git, and service monitoring.

The projects were developed incrementally so that each project built on skills learned in the previous one.

## Project progression

1. Fedora/Linux environment
2. Docker Engine and Docker Compose
3. Nginx container
4. Git-controlled homelab structure
5. NAS storage
6. Samba/SMB network storage
7. Plex Media Server
8. Homelab Docker health monitor

## Current state

The homelab currently has working foundations for:

- Linux administration
- Docker and Compose
- Git-based project management
- NAS storage
- Samba/SMB file sharing
- Plex
- Docker service monitoring
- ntfy notifications
- systemd service management

The next planned project is automated backups.
