# Fedora Linux Foundation

## Overview

Fedora is the Linux operating system used as the foundation of the homelab.

The system uses Fedora with the Hyprland desktop environment and is dual-booted with Windows.

## Goals

The Linux environment provides the foundation for learning:

- Linux administration
- Terminal usage
- Storage management
- Permissions and ownership
- Services
- Docker
- Networking
- Troubleshooting

## Skills developed

During the homelab work, the Linux environment was used for:

- Navigating and managing files from the terminal
- Managing packages and system components
- Working with systemd
- Inspecting hardware and drivers
- Managing disks and filesystems
- Managing users and groups
- Troubleshooting NVIDIA and Docker runtime issues

## Notes

The homelab is intentionally being built on the existing Fedora installation rather than repeatedly reinstalling the operating system.
